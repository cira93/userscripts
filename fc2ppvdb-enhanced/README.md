# FC2PPVDB Enhanced 本地修复版

安装文件：`fc2ppvdb-enhanced.user.js`。在用户脚本管理器中用它更新现有脚本；旧版 `2.1.4` 至 `2.1.9` 保存在 Git 历史中（`git log -- fc2ppvdb-enhanced.user.js`），用于对比和回退；`tests/fixtures/` 里保留 2.1.9 供布局对比测试使用。不要同时启用两个版本。保留既有设置值和数据库结构。

## 2.1.10 搜索页布局与查询恢复

- 修复搜索页使用自定义网格时变成一列：卡片的尺寸隔离使外层自动宽度 flex 项失去内容宽度，结果区收缩。只标记并撑开 `/search` 页面中实际卡片网格的外层结果区，不改搜索表单或其他页面。当前 Firefox 搜索页实测从约 417px 单列恢复为 1133px 四列。
- “站点限制”细分为网站验证、访问拒绝（403 或页面提示）、HTTP 429 请求过多、HTTP 503 服务不可用；辅助标签关闭 / 超时和网络异常单独提示。初始导航的 HTTP 状态无法从页面脚本可靠取得，只报告可识别的页面提示，不编造状态码。
- 加入“重试未确认”按钮：只重试当前页面未确认 / 被限制的作品，保留确定结果；服务端等待期内不可点击，也不能绕过 Retry-After。
- 跨标签通知丢失时补读已保存的任务 / 回执，校验 token 和任务编号以排除旧结果；返回页面时重启被延迟的调度计时器并检查过期任务，辅助页从前进后退缓存恢复时重新注册监听。
- 继续使用已有的站内辅助标签通道，保持每站一个并发和无小时 / 日配额。本版不引入 Android 专用跨站请求通道，不绕过网站验证，不保证操作系统冻结后台标签期间持续执行。

用户已确认平板为 Firefox + Tampermonkey、列表保持前台且显示“站点限制”，因此尚不能将原因认定为后台冻结。新版补足诊断和恢复，平板的具体响应仍需实机验证。桌面搜索页已更新并验收；本地测试覆盖 403 / 429 / 503 / 验证页区分、冷却期间禁止重试、只重试未确认项目、通知丢失与恢复、旧版单列复现及新版桌面 / 窄屏布局。

## 2.1.9 整页查询与进度

- 默认检查当前页面全部已挂载卡片，不需要滚动；原“检查可见卡片”设置自动迁移。新增卡片自动入队，同一站点的重复作品只算一次。不会主动翻页或触发无限滚动加载。
- 左下角显示可收起的进度面板：两个站点各自的已检查 / 总数、有结果、无结果、未确认、站点限制、当前编号和退避倒计时。缓存结果也计入进度；未确认不当作无结果，也不高亮。
- 每站一个并发、两站并行；没有小时 / 每日配额。当前页面已完成的尝试不会因共享缓存过期而重复请求，未确认项目刷新页面后才重新进入调度（仍遵守有效缓存和服务端等待时间）。
- 页面进入后台暂停派发新查询，返回后继续；“仅悬停检查”和“关闭”仍可选择。
- 辅助标签每次查询完成后空闲 30 秒关闭；新任务会重置计时。查询 25 秒未回传、关闭功能或离开页面也会清理。只关闭脚本创建的辅助标签，手动打开的普通标签不会关闭；手动切换到辅助标签不会解除其自动管理。

验证：自动化浏览器测试覆盖不滚动检查屏幕外卡片、动态 / 隐藏卡片入队、重复卡片去重、进度及未确认分类、缓存过期不循环查询、关闭检查隐藏面板，以及普通手动标签保留。已在当前 Firefox 更新并刷新列表，未滚动页面，面板显示 60 / 60（Supjav 30 / 30、MissAV 30 / 30）；此计数包含有效缓存。历史版本的线上验收记录见下文。

## 2.1.8 自动查询通道修复

前几版的跨站 GM 请求在用户环境中不能稳定读取结果，手动打开后回传缓存不能视为实现了自动查询。本版改为自动建立外站浏览器会话：

- 可见卡片自动入队。每站最多一个不抢焦点的后台辅助标签，两站可同时检查；标签内以普通同源 `fetch` 查询后续编号，回传结果后自动高亮，不要求逐条点击。
- 首次辅助标签是正常网站导航，资源按网站正常加载；后续查询只读取 HTML，不将返回页面插入 DOM，也不请求其中的图片或视频。辅助标签空闲 30 秒关闭，关闭检查 / 离开列表也会清理。只关闭脚本创建的标签。
- 保留缓存、同作品去重和跨标签页任务互斥；没有小时 / 每日配额或固定请求间隔。不支持 Web Locks 的环境使用每标签页单并发。
- MissAV 会清除 fragment，辅助任务标识同时放入查询参数，避免标签已打开但没有连接任务队列。
- 若浏览器阻止辅助标签、请求超时、网站真正要求验证码或返回限流，不会伪装成没有结果。验证码不自动解决；服务端 Retry-After 仍被遵守。
- v4 结果缓存避免旧版误判沿用。高亮仅表示存在匹配页面，不验证视频播放。

## 2.1.5 修复与重构

- **演员 / 卖家页面收藏按钮消失**：网站收藏按钮的外层使用 `.tooltip`，原脚本的全局 `.tooltip { display:none }` 误隐藏整个容器。插件提示统一改为 `.fc2-enh-tooltip`，不改变网站收藏逻辑。
- **卡片逐张等待导致网格替换慢**：提取逻辑改为每个列表共用的队列，最多同时处理 8 张；初始扫描与动态插入共用并发限制和 DOM 节点去重。单张卡片仍保留最多 2.5 秒的原图等待时间。
- **动态卡片漏处理**：在初始提取前安装观察器；忽略插件内部 DOM 变化，移除无用的观察器实例。
- **重复作品卡片跳过增强**：FC2CMADB 按 DOM 节点去重，允许同一作品出现在多个位置或翻页后重新出现。
- **无封面时反复扫描整页**：图片索引缺失不再触发全页重建，页面初始化时重置索引；卡片自身的懒加载图片仍受监听。图片等待与演员缓存读取并行，已有演员信息时跳过缓存查询。
- **异步任务残留与失败状态**：清理列表时取消待处理任务、释放节点标记并使旧提取结果失效；只有实际挂载成功才标记完成，失败卡片可再次入队重试。

保留单文件用户脚本形式，本次抽出了队列职责，没有对无关的同步、磁力服务做大规模拆分。
