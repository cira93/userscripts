# 设置功能核对（2.1.6）

结论：并非全部实装到当前界面。该文件包含多个旧站适配器，但用户脚本只匹配 `fc2cmadb.com/*`，而 `/articles/数字` 详情页直接退出。不能把其他站点适配器中的实现等同于当前页面可用。

以下是代码调用链审计，不代表所有远端服务已实测可用。

| 设置 / 功能 | 当前情况 |
| --- | --- |
| 磁力聚合、隐藏无磁力卡片 | 有服务、缓存、UI 事件与过滤逻辑；外部源是否可达仍依赖网络 |
| 历史记录、隐藏已看、批量标记、历史导入导出 | 有本地数据库和业务实现；本次未逐项做数据迁移测试 |
| 网格列数、卡片密度、主题色 | 已接到布局与样式更新 |
| 语言 | 有多语言资源与状态机制；部分直接写在代码里的中文标签未完全国际化 |
| 静态 / 悬停预览 | 有预览加载实现，但注册事件时捕获模式；设置改变没有重新注册的监听，刷新后才按新模式工作 |
| 快捷栏 | 有初始化和状态监听 |
| 演员名称开关 | 默认值、设置绑定和备份字段存在；未找到消费此开关的展示 / 提取分支，当前实际无效 |
| Fourhoi 高清封面开关 | 旧 FD2PPV 适配器读取它；当前 FC2CMADB 提取器不读取，因此对当前网格不生效 |
| 图集预览开关 | 详情增强服务读取它；当前卡片的图集按钮直接创建，未按开关控制，存在行为不一致 |
| 显示番号 | 样式针对 `.fc2-id-badge`，当前画面使用 `.card-cover-identity-line.is-id`，没有覆盖当前番号行 |
| 显示已看按钮 | `statusToggle` 有实现，但当前卡片构建没有把默认启用时的按钮挂入可见区域；仅开关无法解决 |
| 卡片直出操作 | 磁力、图集、左侧站点按钮部分接通；番号 / 已看节点未完整挂载，external 项没有参与实际分配；未勾选项进入隐藏容器，提示里的“更多菜单”并未接通 |
| 外部站点跳转开关 | **2.1.6 已接通当前 Supjav / MissAV 两个按钮的显示与结果检查** |
| 外部站点勾选 | **2.1.6 已接通 Supjav / MissAV**；其他站点虽有 URL 目录，但当前卡片未挂载相应入口，不会因勾选而出现 |
| 隐藏有码 / Supjav 按播放量排序 | 仅 Supjav 分支消费；当前 `@match` 不包含 Supjav，因此当前页面无效 |
| WebDAV / Supabase 同步、同步周期 | 有适配器、同步与调度代码；本次没有连接用户账户验证鉴权、远端写入和冲突处理 |
| 调试日志、关于 | 有日志查看、过滤与导出实现；关于页的脚本链接仍指向旧脚本编号 |

本次新增的是外站结果高亮，以及它依赖的外链显示 / 站点选择开关接线。其余缺口未标为“已修复”。建议后续优先统一卡片操作渲染，再处理封面、演员、图集开关，最后移除或标明不适用于当前站点的选项。

## 2.1.8 调整

当前自动查询通道以 [README.md](README.md) 为准。外站辅助标签由脚本自动打开，不抢焦点，同站任务复用，空闲后关闭；不再依赖用户逐条点击回传结果。每站单并发，无小时 / 每日配额。Supjav / MissAV 不启用旧的整页增强界面。

已在当前 Firefox 列表实测连续自动命中。网站真正要求验证码时仍需要正常完成验证，高亮不保证视频可以播放。

## 2.1.9 调整

“检查可见卡片”已迁移为“检查本页全部卡片”，默认开启整页排队。保留悬停 / 关闭两种模式。左下角增加可收起的进度面板，显示逐站结果及等待状态；只统计本页已加载的唯一作品，不主动翻页。

## 2.1.10 调整

搜索页的自定义网格撑开结果区外层 flex 项，修复单列收缩；原生列数选项不变。外站进度增加具体限制原因和受冷却时间约束的“重试未确认”操作。其他设置缺口仍以本表为准。
