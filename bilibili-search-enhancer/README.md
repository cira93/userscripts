# B站精准搜索 · 自动补页

脚本：`bilibili-search-enhancer.user.js`，版本 **0.3.3**。

## Firefox 更新

篡改猴 → 管理面板 → 打开旧脚本 → 全文替换为本文件夹的 `.user.js` → Cmd+S → 刷新 B站搜索页。不要同时启用多个版本。

## 0.3.3 修正数据已写入但卡片不更新

0.3.2 的诊断显示新增记录字段齐全，但卡片节点仍固定在42个，因此上一版把问题归因于字段转换并不准确。

使用2026-09-19获取的 B站搜索页 HTML 和实际 `index-27be0acf.js` 前端构建，在 Firefox 中离线复现：修改 `VideoList.props.info` 后，数据从42条增至44条，卡片仍为42张；调用该组件的 `$forceUpdate()` 后，原生卡片正常增至44张。

本版在每次写入和回滚列表数据后，请求 Vue 自身更新组件，再检查实际视频链接是否完整。保留现有卡片实例及原生渲染流程，不重新制作卡片，也不绕过失败校验。诊断增加 `updateRequested` 字段。兼容原生列表夹杂的课程等卡片；接管期间解除原生 CSS 对首屏数量之外卡片的隐藏，恢复原始搜索时撤销。

0.3.2 的字段兼容映射继续保留，但它没有解决此次不渲染问题。真实站点回放使用模拟接口并阻断网络，仍需在你的 Firefox + 篡改猴登录环境中确认。

## 0.3.1 修正首屏适配失败

上一版可能把同内容的缓存数组误认为实际渲染源，而且只等待80毫秒判断渲染结果。本版会：

- 逐个验证最多6个候选适配方案，回滚无效修改后尝试下一个。
- 优先更新响应式数组；必要时从 setup/data 绑定处替换数据路径，兼容 shallowRef 和仅监听引用变化的组件。
- 最多等待约1.5秒检查真实渲染，仍严格验证视频集合，不跳过失败校验。
- 不将卡片预览内的次要链接当作额外结果。
- 失败时提供「复制诊断」按钮，也可从篡改猴菜单复制。诊断只包含组件名、字段路径、字段名、条数和等待时间，不包含关键词、视频内容、Cookie 或网址。

**如果刷新后仍然失败，请点「复制诊断」把内容发回来。** 不需要截图或自行操作开发者控制台。诊断用于区分网站结构变化与当前已复现的问题。

## 原生卡片行为

- **完全移除主题修改**：跟随 B站和你已有扩展的配色。旧版深色偏好不再读取。
- **移除自绘卡片**：尝试定位 B站 Vue 原生列表的响应式数据，把筛选、去重后的原始视频记录交回现有组件渲染。
- 搜索框、排序、筛选、视频卡片仍由网站提供；脚本只在列表底部放置进度、加载和暂停按钮。
- 接入成功时，封面、原生事件和“稍后再看”等卡片功能由原组件继续负责。本脚本不复制卡片 HTML，也不实现自己的预览或收藏逻辑。
- **保留原站的失败处理**：找不到可适配的数据列表，或写入数据后组件没有正确渲染，会停止补页、恢复原始列表和分页，并显示“未能接入原生卡片”。不会偷偷换回仿制卡片。

原生组件适配属于实验性实现，依赖 B站当前前端结构。已在 Firefox + Vue 3.5.13 测试夹具以及当前 B站实际前端构建的离线回放中验证，但不能代替你登录状态下的真实 B站测试。遇到适配提示，把提示发回来即可。

## 加载为什么有时自动、有时手动

1. **首次打开**：先保留当前页已命中的原生视频，再尝试补足20条。
2. **后续每轮**：尝试新增20条，最多检查10个原始页面。一个接口页即使只找到1条，也会继续向后查，因此加载可能持续一段时间。
3. **补足后**：接近列表底部250像素时自动开始下一轮。也可主动点“加载更多”。
4. **10页仍不足**：保留已找到的结果，显示检查页数和新增条数，等你点“继续查找”。这是请求上限，**不代表没有更多相关视频**。
5. **连续3页无新视频**：显示重复结果导致暂停，等待手动继续。
6. **你点击暂停、网络错误、风控**：分别显示具体原因。错误时可重试同一页；不会直接跳过去。
7. **接口报告末页**：显示“没有更多相关视频了”，停止扫描。

加载期间显示“本轮已检查 X/10 页，新增 Y/Z 条 · 已用时间”。匹配条件永不自动放宽，也不会把无关内容塞回来凑数。整页处理，最终数量可能略超过目标。

## 匹配和设置

默认要求空格分隔的每个搜索词，都至少出现在标题、简介或标签的一个字段中。连续中文短语不拆字，例如 `机器学习 入门` 是两个必须命中的短语。不做同义词扩展，也不分析视频画面或字幕。

篡改猴菜单提供：
- 切换“仅标题”或“标题+简介+标签”。
- 恢复原始搜索 / 重新启用过滤。

使用原搜索网址中的关键词、排序、时长、分区、时间范围等参数。切换关键词和筛选时取消旧请求，避免串结果。用户、番剧、直播等标签不进行视频补页。原网站显示的搜索总数依旧是原始数量，不是过滤后的数量。

当前仍使用浏览器原有的 B站会话，没有游客模式。搜索请求串行，间隔至少1.2秒；接口风控时停止，不自动重试。无需第三方运行时或本地服务，不读取、打印或上传 Cookie。

## 验证

`tests/search-enhancer.test.cjs` 包含：
- MD5 与 Node crypto 对照、WBI 参考签名、严格匹配、原搜索参数映射。
- Firefox + Vue 生产构建：不依赖开发模式的 DOM 调试属性；验证原卡片 DOM 身份、已有卡片的状态、新增卡片的点击和悬停事件、补页去重、自动加载、暂停原因、换词取消旧请求、原站重新赋值、错误重试、原列表恢复；额外覆盖同内容缓存、shallowRef、延迟渲染导致的首屏适配失败。
- 无法接入原生组件时，保留原页面且不启动后台扫描。
- 实际 B站构建离线回放：首屏过滤、追加5张原生卡片、解除数量隐藏、保留已有卡片节点、恢复原始列表。删除组件更新调用的对照版本可复现渲染失败。

测试使用模拟接口、组件测试夹具和可选的实际站点回放，不使用你的账号。浏览器测试需要 Playwright Firefox；通过 `CODEX_TEST_MODULES` 指定模块目录，通过 `VUE_TEST_RUNTIME` 指定 Vue 3.5.13 的 `vue.runtime.global.prod.js` 本地路径。实际站点回放另通过 `BSE_SITE_HTML` 和 `BSE_SITE_BUNDLE` 指定已保存的公开搜索页 HTML 与对应 JS 构建；不指定时该测试跳过。这些仅用于测试，不是安装脚本的前提。

```sh
node --test tests/search-enhancer.test.cjs
```

未提供浏览器测试依赖时，相应测试会跳过。
