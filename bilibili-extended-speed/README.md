# Bilibili 扩展倍速

一个不需要联网权限的 Tampermonkey 用户脚本，在 Bilibili 播放器原来的“倍速”位置提供最高 `10x` 的速度菜单，并在视频提供字幕时默认开启字幕。

## 倍速档位

- 原有档位：`0.5 / 0.75 / 1 / 1.25 / 1.5 / 2`
- `2x–5x`：间隔 `0.5x`
- `5x–10x`：间隔 `1x`

完整档位为：

`0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 / 2.5 / 3 / 3.5 / 4 / 4.5 / 5 / 6 / 7 / 8 / 9 / 10`

## 安装

1. 在浏览器中安装 Tampermonkey。
2. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
3. 删除编辑器中的默认内容。
4. 复制 [`bilibili-extended-speed.user.js`](./bilibili-extended-speed.user.js) 的全部内容并粘贴、保存。
5. 刷新已经打开的 Bilibili 视频页面。

把鼠标移到播放器底部的“倍速”按钮上，即可看到单列倍速菜单；菜单超出可用高度时可以在内部快速滚动。脚本支持普通视频、番剧、活动页和稍后再看页面，并会在站内切换视频或播放器重新加载后保持本次页面中所选的速度。

如果当前视频提供字幕，脚本会优先开启 AI 中文字幕，其次选择其他中文字幕，最后选择第一个可用字幕。自动开启只在视频加载时执行一次；之后仍可使用 Bilibili 原生字幕菜单手动关闭或切换语言。

## 说明

- 脚本只访问当前页面中的 `<video>` 元素，不发送网络请求，也不读取账号信息。
- 在非常高的倍速下，声音可能静音、断续，画面也可能受电脑解码性能影响；这是浏览器和设备的媒体播放限制。
- 如果 Bilibili 改版后按钮没有出现，可先确认脚本已启用，然后刷新页面。
