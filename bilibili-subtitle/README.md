# B站字幕和评论提取 · 篡改猴脚本

支持普通 `https://www.bilibili.com/video/BV…` / `av…` 视频页。

- 字幕：读取当前分 P 的已有字幕，选择语言后导出 UTF-8 TXT 或毫秒时间轴 SRT。
- 评论：按时间分页读取整个视频可访问的一级评论、置顶/热评及楼中楼，按评论 ID 去重，导出 TXT、CSV、JSON 和采集报告。
- 进度：每页评论和下一页进度在同一个 IndexedDB 事务中保存；支持暂停、刷新后继续、失败楼层重试和跨标签页互斥。

脚本文件仍叫 `bilibili-subtitle.user.js`，当前版本为 2.0.1，保留原来的字幕功能和脚本 namespace。

## 安装或升级

1. 打开 `bilibili-subtitle.user.js`，复制全部内容。
2. 已安装旧版时，在篡改猴中打开原脚本，用新内容全部替换并保存。首次安装时，点击「添加新脚本」，删除默认内容后粘贴并保存。避免同时启用新旧两个副本。
3. 在 B 站网页登录，打开或刷新一个普通视频页。右下角出现「字幕 / 评论提取」。
4. Chromium 浏览器若提示用户脚本权限未开启，请按篡改猴提示开启“允许用户脚本”或开发者模式，参见 [官方说明](https://www.tampermonkey.net/faq.php#Q209)。

进入网页全屏或播放器原生全屏时，按钮和已展开的面板会自动隐藏，退出后恢复原先的展开状态；隐藏期间评论采集继续运行。正常视频页没有按钮时，检查脚本是否启用、篡改猴是否获得 B 站访问权限，并刷新页面。

## 提取评论

1. 打开面板，在「整个视频 · 评论与楼中楼」下点击「开始采集」。脚本会核对当前登录账号和视频，先遍历一级评论，再逐楼读取全部可访问回复。
2. 默认请求间隔为 **2 秒 + 0～0.5 秒随机等待**，可设置为 1.5～60 秒。评论采集的登录核对、视频信息和结束数量校验也使用这个间隔。没有人为设置的评论条数上限，大评论区会花费较长时间。
3. 面板显示去重后的一级评论、楼中楼、已读页数、完成/待处理/失败楼层、接口最近总数及差额。
4. 可点击「暂停」。等待中的定时器和正在进行的请求会取消；已提交的页面保留，尚未提交的页面继续时重新读取。
5. 刷新或关闭标签页后，再次打开同一视频，面板会读取本地进度；点击「继续采集」恢复。刷新本身不自动请求 B 站接口。
6. 随时下载「评论 TXT」「评论 CSV」「评论 JSON」。另可下载「采集报告 JSON」。文件名标注“未完成”“遍历结束”或“遍历结束_有差异”。
7. 遍历结束后，如存在失败的不可访问楼层，可点击「继续 / 重试失败楼层」。重新采集最新快照时，先导出已有结果，再点击「清空本地进度」，然后重新开始。

评论是整个视频共用的，切换分 P 不会重新采集；切换到另一个视频会暂停旧任务并切换本地进度。AV/BV 两种链接对应同一份视频进度。进度按视频和登录账号分别保存，继续时重新核对账号，避免混合不同账号的可见范围。

只允许一个标签页写入同一视频、同一账号的进度。另一个标签页会提示先暂停已有任务。该保护使用浏览器 Web Locks API，需要支持该 API 的现代浏览器；本地数据库或安全锁不可用时会明确停止。

## 导出内容与完整性

- 保存评论 ID、根评论 ID、回复目标 ID、UID、昵称、UTC 发布时间、点赞数和完整多行正文。JSON 还保存图片 URL、尺寸和表情图片映射；TXT、CSV 包含图片 URL，不下载图片本体。
- 一级评论按发布时间降序排列，每个楼层后面跟随其楼中楼；楼中楼按发布时间升序排列。回复其他楼中楼的关系通过 `parent_id` 保留。
- JSON 包含 `report` 和 `comments`；采集报告包含接口首次/最近总数、实际采集数、总差额、逐楼应有/实有数量、失败页面和恢复记录。TXT 也附带范围说明和失败记录。CSV 请同时下载报告。
- CSV 对引号和换行进行转义，对可能被表格软件解释为公式的昵称/正文加前置单引号；原始正文以 JSON 为准。CSV 中长 ID 请按文本列导入，避免 Excel 将其舍入；JSON 中 ID 始终按字符串保存。
- `incomplete` 表示尚未遍历结束；`finished_with_gaps` 表示已到达分页末尾，但有数量差异或失败楼层；`traversal_finished` 表示可访问分页遍历结束且当前统计没有发现差额。

**遍历结束、数量一致都不能证明获取了平台上的全部历史评论。** 已删除、审核未公开、权限不可见的内容无法保证获取。评论精选、折叠、采集期间新增或删除，都可能导致差额。报告会记录接口提供的精选/折叠提示和观察到的数量变化。中断数天后，平台的旧分页游标也可能失效，届时可以导出已有结果，清空后重新采集。

网络错误、超时和 HTTP 5xx 最多自动重试 2 次，分别等待 3 秒和 6 秒。登录失效、限流、安全验证、签名错误、异常分页、重复游标或重复页面会立即暂停，保留当前位置。按面板提示在 B 站网页检查后手动继续。单个楼中楼返回“不可访问”时记录失败并继续其他楼层，结束后可重试。

## 字幕使用与范围

点击「读取字幕」→ 选择字幕语言 →「下载 TXT」或「下载 SRT」。切换分 P 或视频后，重新读取。文件名包含视频标题、BV 号、分 P 和语言。

- 字幕仅下载当前分 P；作者字幕、AI 字幕是否可用取决于接口返回的字幕列表。
- 字幕要求登录时，在 B 站网页登录后重新读取，无需复制 Cookie。
- 没有字幕时会提示。烧录在画面内的文字无法作为字幕文件直接提取，不包含语音转文字。
- 暂不支持番剧、课程、互动视频分支或多视频批量任务。

## 数据保存与异常恢复

评论和进度保存在 **当前浏览器、当前配置文件的 B 站站点 IndexedDB** 中。清理站点数据、无痕窗口关闭或卸载浏览器可能使进度丢失，重要结果请及时导出。导出时读取最后一次已提交的数据，避免正在写入的页面造成内容和进度不一致。存储空间不足时停止采集并恢复上一次已提交的进度，不会只推进游标而漏掉评论。

脚本不上传视频、字幕或评论到第三方，不保存或导出 Cookie。只按点击或采集任务请求 B 站视频、字幕、登录信息和评论接口及字幕 CDN；视频和评论接口使用浏览器当前登录态，字幕文件请求不携带凭据。自动检查 URL 和本地恢复不请求网络。本项目不是 B 站官方工具，接口变化时可能需要维护。

## 本地验证

核心测试无需安装依赖，使用 Node.js：

```sh
node --check bilibili-subtitle.user.js
node --test tests/subtitle.test.cjs tests/comments.test.cjs
```

浏览器测试需要可用的 Playwright 和 Chromium：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node --test tests/browser.test.cjs
```

也可运行 `node --test tests/*.test.cjs`；未安装 Playwright 时会跳过可选浏览器测试。测试夹具接管全部网络，**不使用真实账号，不代表已经在真实 B 站登录态下验收**。

自动验证包含原有字幕回归、WBI 签名和长 ID 精度、一级/楼中楼分页去重、分阶段暂停续传、异常分页、失败楼层重试、限流停止、三种文件下载、原生 IndexedDB 事务回滚、跨标签页互斥以及跨视频陈旧响应隔离。

真实浏览器验收建议：在有少量评论的视频核对一级和楼中楼正文及回复关系；采集一部分后暂停并刷新继续；确认 TXT/CSV/JSON 和报告；切换分 P、切换视频；核对字幕 TXT/SRT 仍正常。大型评论区的耗时和覆盖范围取决于 B 站当前接口及账号可见性。
